# Hugo Trade Shield: free sanctions name check

Search a person, company or ship against the US Consolidated Screening List (OFAC, BIS, State), the UN Security Council list and the UK Sanctions List. Runs in the browser; names are not sent anywhere.

Live: https://opiiusservice-prog.github.io/trade-shield/

Not legal advice. Lists are public data from data.trade.gov, un.org and gov.uk.
